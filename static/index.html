WELCOME TO PLANNET

A place for every plan.

Make it yours

Use ＋ New tab to create a space. Open a tab and choose Edit tab to rename it, change its color, reorder it, or delete it. Add categories to organize your projects.

Tasks, with room to grow

Choose New task, or ＋ Task in a category. Use the ＋ beside a task to add a subtask. The chevron folds or unfolds subtasks. Click a task title to edit its details.

Finish one thing at a time

Tick the checkbox to complete a task. Each subtask is independent: completing a parent leaves unfinished subtasks open. Enable Show completed to find or reopen finished items.

Know what comes next

Green means due today; red means overdue. Overview brings today’s work first, then overdue, upcoming, and undated tasks. Click a summary card to focus on one group. Dates follow the time zone you choose using the clock above your workspace.

Timed tabs

In New tab or Edit tab, enable Timed tab. Set a start date/time and add tasks directly with New task. Each duration determines the next task’s start; the schedule can span several days. Drag the six-dot handle to reorder, or focus it and use the up/down arrow keys. Use Add an existing task to include work from another tab. Removing a task from the schedule keeps the original in Overview. Add sleep or breaks as tasks when needed. Completed tasks keep their planned time slots. Existing day plans are converted to timed tabs.

Delete and back up

The × beside a task deletes it after confirmation. Deleting a parent also deletes its subtasks. Deleting a category or tab includes the tasks inside it. Download a Backup before large changes.

Your data stays here

Changes save automatically to this computer. Start Plannet using Start Plannet.bat; keep its server window running while using the app. Reopening the app restores your data.

Greeting & time zone

Greeting time, clock, and deadlines follow this time zone. Automatic language uses Filipino for Manila, Japanese for Tokyo, Chinese for supported Chinese-region zones, Spanish for supported Spanish-region zones, and English elsewhere. You can override it above. Preferences are saved in this browser.
